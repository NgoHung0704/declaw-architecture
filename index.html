01 / PROCESS

Một lõi Python

CLI, agent, tool registry, documents, sanitizer, memory và audit là các module trong cùng ứng dụng. Worker plugin chạy ở subprocess; Ollama là dịch vụ riêng.

02 / DATA

Mã hóa có phạm vi

Text payloads trong Chroma được mã hóa. Embedding vectors và một số metadata không được mã hóa; SQLite không được mô tả là mã hóa toàn bộ.

03 / ROADMAP

Phần chưa triển khai

Gateway FastAPI, trải nghiệm desktop kết nối và shell sandbox chưa thuộc đường chạy CLI hiện tại. HTTP observer là quan sát trong process, không phải OS firewall.
